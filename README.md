# Salooan
## Dynamic Collateral Haircut Estimation

This project aims to estimate dynamic collateral haircuts for cryptocurrency and equity assets using machine learning models. 
It processes market data, extracts features, trains predictive models, and evaluates their performance in estimating appropriate 
collateral requirements under varying market conditions. The system is designed to be extensible for different asset classes 
and prediction horizons.

Status: Milestone 0 (scaffold) complete
